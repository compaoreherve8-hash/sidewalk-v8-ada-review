SIDEWALK RAMP CALCULATOR V8 — ADA/MnDOT DESIGN SCREEN (NOT CERTIFICATION)

This edition improves upon V7. It provides screening checks for ordinary MnDOT/PROWAG curb ramp cases and a mandatory engineering review checklist. It does NOT generate an official ADA/MnDOT compliance certificate.

IMPORTANT: All values are illustrative until entered and verified against site surveys and the governing project standards. Cross slope 2% is the conservative MnDOT design screen; federal PROWAG uses 1:48 (approx. 2.1%) in many ordinary situations. Landings are checked against 4x4 ft and 2% slopes. PROWAG exceptions and project-specific exceptions are not automatically authorized. Sidewalk run slope >5% can be an exception under R302.4.1 only when substantiated against established adjacent road grade and the correct applicable condition. Landing serving two ramps has additional PROWAG requirements. Some geometries need different rules; review all applicable documents.

The preliminary removal formula retains the user's ABSOLUTE slope-difference estimator solely for comparative early design. The tool explicitly flags that it cannot verify signed grade/elevation closure and actual demolition limits. The 25-ft review threshold is NOT a confirmed regulation.
